# 城市图片素材规则与来源状态

## 使用规则

1. 城市图必须展示该城市的可识别地标、山水、天际线或地域建筑，不用普通街景代替。
2. 同一封面不得用于两座城市；加载失败时隐藏图片并显示城市卡片自己的莫兰迪占位背景。
3. 页面仅展示图片和准确中文 `alt`；作者、许可与原始链接集中保存在素材清单，不把长网址堆到页面。
4. 新素材必须记录城市、文件名、作者、来源页、原始文件、许可、尺寸与获取时间，缺任一关键项则不用。
5. AI 装饰图必须标记“AI 视觉创作”，不得充当真实景点照片。

## 已完整记录

`public/cities/attribution.json` 记录 21 张新增城市图片。大部分来自 Wikimedia Commons 的开放许可素材；香港使用 Unsplash License。澳门图片为大三巴牌坊，敦煌图片为莫高窟，张家界为石英砂岩峰林，避免与黄山、桂林混用。
