## 图片处理规则

- 图片只在对象具有百科条目主图、Wikimedia Commons 文件页、作者与明确许可时进入候选。
- 本地统一转为 1200×800 WebP；页面使用响应式尺寸、延迟加载与城市专属失败占位。
- 合并时按原始图片 URL 跨城市去重；重复图片不进入前台。
- 首页卡片只有在上游城市首图同时具备有效来源页和许可时才计为合格；本地文件存在不能替代授权检查。
- 页面只展示折叠的“图片与资料来源”，不在卡片下堆放原始长链接。
- 自动匹配之后仍抽查对象标题和画面；不确定时宁缺毋滥。
